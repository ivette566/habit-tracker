# Habit Tracker - Semana 2

Aplicación web para gestionar hábitos utilizando **Next.js**, **Redux**, **Express.js** y **MongoDB Atlas**.

## Estructura del proyecto
- `frontend/` → Aplicación en Next.js con Redux y TailwindCSS.
- `backend/` → API en Express.js conectada a MongoDB Atlas.

## Requisitos previos
- Node.js v22 o superior
- NPM (incluido con Node.js)
- Cuenta en [MongoDB Atlas](https://www.mongodb.com/atlas)
