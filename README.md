# Habit Tracker API

Proyecto académico para gestionar hábitos utilizando **Node.js**, **Express** y **MongoDB Atlas**.  
Este proyecto corresponde a la **Actividad 1 - Semana 1** del curso, donde se realiza el setup inicial del backend.

## Requisitos previos
- Node.js v22 o superior
- NPM (incluido con Node.js)
- Cuenta en [MongoDB Atlas](https://www.mongodb.com/atlas)
- Thunder Client o Postman para pruebas
